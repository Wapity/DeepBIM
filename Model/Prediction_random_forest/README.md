# Energy Efficiency Optimization using Random Forest
This study looks into assessing the heating load and cooling load requirements
of buildings (energy efficiency) as a function of building parameters.

## Technologies and Tools
* Python 3.5
* scikit-learn

## Commands
Put the new parameters to predict energy efficiency for in bim_prediction.csv

To train, test (with bim_train.csv) and predict new heating and cooling (from bim_prediction.csv):
python train_predict.py

# DeepBIM - Model

# Energy Efficiency Optimization using Neural Networks
This study looks into assessing the heating load and cooling load requirements
of buildings (energy efficiency) as a function of building parameters.

## Technologies and Tools
* Python 3.5
* TensorFlow
* CPU

## Commands
To train and test :

python train.py

To predict new heating and cooling by loading the best model :

Put the new parameters in bim_prediction.csv

Run:

python predict.py
